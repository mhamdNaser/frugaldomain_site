टेक्स्ट और JSON डिफ़

किसी भी चीज़ के दो संस्करणों की तुलना करें, कॉन्फ़िग फ़ाइल, अनुवाद या अनुबंध, और लाल-हरे की दो दीवारों की जगह हर बदली पंक्ति के भीतर बदले शब्द देखें। जो आप पेस्ट करते हैं वह इसी टैब में रहता है।

  • बारीकी: पंक्ति और शब्द के स्तर पर
  • एक्सपोर्ट: Unified diff
  • आपके दस्तावेज़: टैब से बाहर नहीं जाते

पहले

मूल संस्करण। इसे पेस्ट करें, या फ़ाइल खोलें।

बाद में

बदला हुआ संस्करण, जिसकी “पहले” से तुलना होती है।

शब्दों का चिह्नित होना क्यों मायने रखता है

पंक्ति की तुलना बताती है कि पंक्ति बदली; शब्द की तुलना बताती है कि कौन-सा शब्द बदला। कॉन्फ़िग फ़ाइल या अनुवाद में यही पूरा जवाब है, और इसीलिए बदली हुई पंक्ति यहाँ दो बार दिखती है: एक बार जो निकला उसके साथ, और एक बार जो आया उसके साथ।

पंक्तियाँ कब जोड़ी नहीं जातीं

अगल-बगल की दो पंक्तियाँ ज़रूरी नहीं कि एक-दूसरे का पुनर्लेखन हों। जब हटाई और जोड़ी गई पंक्ति में बहुत कम साझा हो, तो उन्हें एक ऐसी पंक्ति में दिखाने की बजाय जिसमें हर शब्द चिह्नित हो, अलग-अलग दिखाया जाता है, क्योंकि वह शोर जैसा पढ़ा जाता है।

JSON के लिए, इसकी जगह path से तुलना करें

JSON पर टेक्स्ट तुलना किसी कुंजी का क्रम बदलने को बदलाव गिनती है और दोबारा इंडेंट करने को सौ। JSON टूलकिट path से तुलना करता है, बदली हुई हर वैल्यू की एक पंक्ति, और पेलोड के लिए आम तौर पर आप यही चाहते हैं, फ़ाइल के लिए नहीं।

अक्सर पूछे जाने वाले प्रश्न

ऑनलाइन दो टेक्स्ट की तुलना सुरक्षित तरीक़े से कैसे करें?
ऐसा टूल इस्तेमाल करें जो तुलना ब्राउज़र के भीतर करे। जिसकी तुलना होती है वह अक्सर कॉन्फ़िग फ़ाइल, अनुबंध या अनुवाद होता है, जिसे एक शब्द का फ़र्क़ पता करने के लिए सर्वर पर भेजना ठीक नहीं।
unified diff फ़ॉर्मेट क्या है?
वह फ़ॉर्मेट जिसे git और patch इस्तेमाल करते हैं: हर बदलाव के आसपास कुछ संदर्भ पंक्तियाँ, हटाई गई के लिए - और जोड़ी गई के लिए + चिह्न। यह मर्ज रिक्वेस्ट या टिकट में पेस्ट करने के लिए सही फ़ॉर्मेट है, और टूल इसे एक्सपोर्ट करता है।
कुछ बदलाव अलग-अलग हटाने और जोड़ने के रूप में क्यों दिखते हैं?
क्योंकि वे दोनों पंक्तियाँ एक-दूसरे का पुनर्लेखन नहीं हैं। जब हटाई और जोड़ी गई पंक्ति में टेक्स्ट बहुत कम साझा हो, तो उन्हें जोड़ने से ऐसी पंक्ति बनती है जिसके लगभग सारे शब्द रंगे होते हैं, जो उन्हें अलग-अलग दिखाने से कम साफ़ है।
क्या यह टूल JSON फ़ाइलों की तुलना के लिए ठीक है?
फ़ाइलों के लिए हाँ। लेकिन API पेलोड की तुलना JSON टूल से path के आधार पर करना बेहतर है, क्योंकि टेक्स्ट तुलना क्रम और इंडेंटेशन के अंतर को बढ़ाकर दिखाती है।
