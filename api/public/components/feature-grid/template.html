Built to be copied

Every decision in this library follows from one rule: a template has to be readable before it is trusted.

One file, no dependencies

Markup, styles and behaviour travel together. Nothing is fetched at runtime, so a template works offline and behind a strict content policy.

Pictures without image files

Avatars, charts and product shots are drawn as inline SVG or CSS gradients. They stay sharp at any size and never 404.

Light and dark, from tokens

Four variables at the top of each file carry the whole theme. Retheming a component takes a minute, not a rewrite.

Accessible by construction

Real labels, visible focus rings, keyboard paths and states that do not rely on colour alone.

Arabic and right-to-left

Every component carries an Arabic name and uses logical properties, so adding dir="rtl" flips it properly.

Readable in one sitting

No framework, no minified blob. You can read a whole template before pasting it into a client project.
