表单

把纸上收集的信息搬到线上

问题只需创建一次，分享链接后，答复会汇总到可导出为电子表格的表格中，列的顺序与你现有的表格保持一致。

  • 一个链接，无需账号

    分享链接，任何人都能填写。无需注册，打开的页面也没有多余的菜单分散注意力。

  • 牢靠的校验规则

    恰好十一位的身份证号、不含数字的字母、范围内的日期、无人重复提交的值，全部由服务器校验，而不仅仅依赖浏览器。

  • 答复附带照片

    要求上传证件后，图片会随答复一并保存，显示在表格中，并直接嵌入导出的电子表格，而不是仅提供链接。

  • 答复存入你自己的数据库

    答复与网站分开存储，仅提供给创建该表单的人。

快速开始

只需 两行代码

引入样式表，即可通过类名使用任意图标。无需构建步骤，也无需安装任何包。

1

添加 CSS 文件

<link rel="stylesheet" href="https://cdn.frugaldomain.site/icons.css">

在 <head> 中引入一次，即可使用所有图标。

2

使用图标

<i class="frugal frugal-bell"></i>

将类名添加到任意元素即可，可直接从图标库复制粘贴。

3

或下载后编辑

想自己持有文件？下载 SVG 后即可在你自己的工具中直接编辑。

组件

界面模板， 复制即用

两百多个表格、表单、仪表盘和界面元素，每类超过五十个。每个模板都是单个文件，粘贴进项目之前几分钟就能读完。

  • 每个模板都是独立的 HTML 文件：无需构建、没有依赖，运行时也不会请求任何外部资源。
  • 每个模板都内置浅色和深色主题，由文件顶部的四个变量控制。
  • 采用 CSS 逻辑属性编写，所有布局在阿拉伯语及从右到左的排版下都能正确镜像。
  • 在终端中运行 npx frugal add 即可安装，也可以让编程智能体通过 MCP 获取。
