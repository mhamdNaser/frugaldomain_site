为什么要统一 alef

أ إ آ ا 对读者是同一个字母，对模型却是四个不同的 token。保留四种写法的语料会让模型把容量花在拼写差异上而不是语言上，保留它们的搜索索引也匹配不上用另一种键盘输入的同一个词。

为什么变音符号并不总是噪声

删除 tashkeel 能大幅减少 token 数，对普通文章是正确的。但对《古兰经》文本、诗歌和教学材料则是错误的，因为这些符号承载含义和读音。所以它是一个开关，而不是默认行为。

没人看得见的字符

方向标记和零宽连接符会在从 PDF 或聊天应用复制粘贴时保留下来，然后藏在 JSONL 文件里，任何审阅者都发现不了。它们会改变 token 数、破坏精确匹配，本页会按名称和数量报告它们。

常见问题

为什么在建立索引或训练前要规范化阿拉伯语文本？
أ、إ、آ、ا 对读者是同一个字母，对模型却是四个独立的 token。保留四种写法的语料会把精力花在拼写差异上而不是语言上，保留它们的搜索索引在同一个词换了写法后也匹配不上。
是否应该总是删除变音符号？
不。删除变音符号能大幅减少 token 数，对普通文章是正确的，但对《古兰经》文本、诗歌和教学材料是错误的，因为这些符号承载含义和读音。所以它是可选开关，而不是默认行为。
数据集中的不可见字符是什么？
包括方向标记、零宽连接符与非连接符，以及类似的格式字符。它们在从 PDF 和聊天应用复制粘贴时保留下来，悄悄藏进 JSONL 文件，改变 token 数并破坏精确匹配。本页会按名称和数量把它们找出来。
工具能处理阿拉伯-印度数字吗？
可以。可以把 ١٢٣ 这类数字转换为 123，使比较和排序与其余数据保持一致。
