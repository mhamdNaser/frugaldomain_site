这些工具是如何构建的

了解你的数据去向

大多数开发者工具在浏览器中处理粘贴的文本和文件。图片转换器是个例外：它会将所选图片上传到我们的转换 API。使用敏感数据前，请先查看各工具的说明。

带日期的数字

当工具引用价格、上下文窗口等数字时，会标明核实日期并链接到来源页面。给出言之凿凿却没有来源的数字，正是此类工具的常见毛病。

默认双语支持

我们对阿拉伯语的处理是刻意设计的：令牌估算会计入其编码效率较低的因素，专门有一个工具用于预处理阿拉伯文，布局在从右到左排版下也能正确镜像。

常见问题

这些工具免费吗？
是的，开发者工具完全免费，无需账号。大多数工具在浏览器中处理输入；图片转换器会将所选图片上传到转换 API。
我粘贴的内容会上传到服务器吗？
大多数工具在浏览器内处理文本和文件，包括 JSON 和训练数据。图片转换器则会将所选图片上传到转换 API 进行处理。
这些工具支持阿拉伯语吗？
支持，而且是刻意设计的。令牌估算会计入阿拉伯语编码效率较低的因素，另有专门的阿拉伯文规范化工具，模拟数据生成器会生成真实的阿拉伯语姓名和城市，所有工具界面都支持从右到左排版。
这些页面上的数字从哪里来？
当工具引用某个数字（如模型价格或上下文窗口大小）时，会标明核实日期并链接到来源页面，因为这些数字可能不经通知就发生变化。
