工作方式

三步，从 Shopify 到一目了然

  1. 1. 连接你的店铺

    填写店铺的 myshopify 域名和 Admin API 访问令牌。连接会立即验证，令牌加密存储。

    约 3 分钟

  2. 2. 我们同步一切

    商品目录、订单、客户、库存和内容会被导入，之后 Shopify webhook 让每次变更在发生时就同步进来。

    此后实时更新

  3. 3. 在一个地方统一管理

    浏览、筛选、导出和编辑。你的修改会先提交给 Shopify，只有 Shopify 接受后才显示为已保存。

    天生双向

你可以管理什么

整个店铺，一个清爽的工作区

  • 目录、变体与商品系列

    每件商品及其变体、选项、媒体、供应商、类型和标签。在专注的编辑器中修改变体，让商品系列井井有条。

  • 订单与草稿订单

    完整的订单时间线，含商品、税费、退货和风险，另有草稿订单和弃单购物车。

  • 客户

    资料、地址、订单历史和营销同意状态，集中在一处。

  • 库存

    按地点查看库存，表格专为快速浏览而设计。

  • 履约与配送

    履约单、物流跟踪和退货，以及你的配送区域。

  • 折扣与财务

    折扣、优惠码及其使用情况，支付交易和退款。

  • 市场与订阅

    各市场及其价目表、销售方案和订阅合约。

  • 内容与文件

    博客、文章、页面、菜单、元字段和你的媒体库。

双向同步

实时，双向

Shopify 通过已验证的 webhook 推送变更；你的修改经由会自动重试的队列发回，不会在途中丢失。

  • 经过验证的 webhook

    一有变化 Shopify 就会通知我们。每个 webhook 都先校验签名，再进入后台队列处理。

  • 可审计的出站同步

    你的修改会作为可追踪的任务发回 Shopify。每次尝试都有记录，失败可见并会重试。

  • 提前知晓，不会意外

    应用内通知和同步中心让你随时了解导入、更新以及任何需要再看一眼的事项。

安心与舒适

安全上严谨，使用上轻松

  • 加密的访问令牌

    你的 Shopify Admin API 令牌在存储时加密，仅在与 Shopify 通信时才会解密。

  • 签名校验的 webhook

    收到的 webhook 会用 Shopify 的签名校验，未签名的一律拒绝。

  • 角色与权限

    只给每位成员所需的权限，可细化到仪表盘的各个部分。

  • 五种语言，完整支持从右到左排版
  • 浅色与深色主题
  • 为店主及其团队而建

常见问题解答

连接店铺需要准备什么？

店铺的 myshopify.com 域名，以及在 Shopify 后台自定义应用中获取的 Admin API 访问令牌。连接会立即验证，令牌加密存储。

数据是实时更新的吗？

是的。首次导入后，FrugalDomain 会监听 Shopify webhook，订单、商品、客户和库存在 Shopify 中变化后片刻内就会更新。

我在这里做的修改会同步到 Shopify 吗？

会。每次修改都会排队发送给 Shopify，Shopify 繁忙时自动重试，只有 Shopify 接受后才显示为已保存。如果 Shopify 拒绝，你会看到原因。

团队可以使用吗？支持哪些语言？

可以。邀请成员并为每人分配所需权限。工作区支持英语、阿拉伯语、印地语、中文和土耳其语，阿拉伯语采用完整的从右到左布局，并提供浅色和深色主题。

需要付费吗？

不需要。Shopify 店铺管理包含在免费方案中，连接店铺也无需添加支付方式。
