التثبيت من الطرفية

أمر واحد يكتب الملف داخل مشروعك. لا حساب ولا مفتاح ولا إعدادات.

npx frugal-cli list --category tables
npx frugal-cli add users-directory-table --dir ./src/ui

دع وكيل البرمجة يجلبه

الحزمة نفسها تعمل كخادم MCP، فيستطيع Claude Code أو Cursor البحث في المكتبة وتثبيت المكوّن بنفسه.

claude mcp add frugal -- npx -y frugal-cli mcp
