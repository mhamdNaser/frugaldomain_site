Why the iOS icon is filled

Safari composites a transparent home-screen icon onto black, so a logo drawn in dark ink disappears. apple-touch-icon.png is always given a background here, whatever the others use.

What maskable means

Android crops an adaptive icon to whatever shape the launcher uses - a circle, a squircle, a rounded square - and can take twenty per cent off every edge. The maskable file therefore keeps the artwork well inside that safe area.

About favicon.ico

The .ico here holds 16, 32 and 48 pixel images as PNGs inside the container, which every browser since Vista reads. It is still worth shipping: bookmarks, older browsers and some feed readers ask for /favicon.ico by name and ignore the link tags.

Frequently asked questions

What favicon sizes do I actually need?
A favicon.ico holding 16, 32 and 48 pixel images, PNG tab icons, a 180 pixel apple-touch-icon for iOS, the Android icons and a maskable variant. This page produces all of them from one drawing, plus the manifest and the link tags to paste into your head.
Why is the iOS icon given a background?
Safari composites a transparent home-screen icon onto black, so a logo drawn in dark ink simply disappears. apple-touch-icon.png is therefore always generated with a background here, whatever the other sizes use.
What does a maskable icon mean on Android?
Android crops an adaptive icon to whatever shape the launcher uses - a circle, a squircle, a rounded square - and can take about twenty per cent off every edge. The maskable file keeps the artwork well inside that safe area so it survives any launcher.
Do I still need favicon.ico?
Yes, it is still worth shipping. Bookmarks, older browsers and some feed readers request /favicon.ico by name and ignore the link tags entirely. The .ico produced here holds the 16, 32 and 48 pixel images as PNGs inside the container, which every browser since Vista reads.
