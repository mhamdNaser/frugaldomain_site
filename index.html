Forms

Collect what you used to collect on paper

Build the questions once, share the link, and watch the answers arrive in a table you can export as a spreadsheet - with the columns in the order your own sheet already has them.

  • One link, no accounts

    Share a link and anyone can answer it. Nobody has to sign up, and the page they open carries no menu to wander off through.

  • Rules that hold

    A national id of exactly eleven digits, letters with no numbers in them, a date inside a range, a value nobody else has given - checked on the server, not only in the browser.

  • Photographs with the answers

    Ask for a document and the picture is kept with the response, shown in the table, and embedded in the exported sheet rather than linked from it.

  • Your answers, your database

    Responses are stored apart from the site and served only to the person whose form collected them.

Get started

Add the library in two lines

Link the stylesheet, then use any icon by class name. No build step and no package to install.

1

Add the CSS file

<link rel="stylesheet" href="https://cdn.frugaldomain.site/icons.css">

Include it once in your <head> to make every icon available.

2

Use an icon

<i class="frugal frugal-bell"></i>

Apply the class to any element. Copy and paste straight from the gallery.

3

Or download and edit

Prefer to own the file? Download the SVG and edit it directly in your own tooling.

Components

Interface templates, ready to copy

Over two hundred tables, forms, dashboards and interface elements - more than fifty in each category. Every one is a single file you can read in a sitting before you paste it into a project.

  • One self-contained HTML file each - no build step, no dependencies, nothing fetched at runtime.
  • Light and dark themes in every template, driven by four variables at the top of the file.
  • Written with logical CSS properties, so every layout mirrors correctly in Arabic and right-to-left.
  • Install one from the terminal with npx frugal add, or let a coding agent fetch it over MCP.
