Decoding is not verifying

Anyone can read a JWT - the payload is base64, not encryption. What proves it came from your server is the signature, and checking that needs the key. A tool that only decodes tells you what the token claims, not whether the claim is true.

Why alg "none" is flagged

A token whose header says alg: none carries no signature at all. Libraries that honour that header accept a token anyone could have written - the oldest JWT attack there is, and still found in the wild. This page marks it as an error rather than decoding it quietly.

Never paste a private key

RSA verification needs only the public half, which is published by design. Nothing legitimate asks you to paste a private key or an HMAC secret into a web page you do not control - including this one, which is why the whole check runs locally and the page says so.

Frequently asked questions

Is it safe to paste a JWT into an online decoder?
Usually not. A JWT is a bearer credential: whoever holds it can act as its subject until it expires, so pasting a live token into a server you do not control hands over an account. This page decodes and verifies entirely in your browser - you can open it, disconnect from the network, and it still works.
How do I verify a JWT signature without a server?
The browser's own WebCrypto implementation does it. Paste the shared secret for an HS256 token, or the public key in PEM form for RS256, and the check runs locally. Never paste a private key or a production HMAC secret into a page you do not control.
What does alg: none mean in a JWT?
It means the token carries no signature at all. Libraries that honour that header accept a token anyone could have written - the oldest JWT attack there is. Reject them at the library level and pin the algorithms you accept.
Why can it not verify ES256 tokens?
Elliptic-curve tokens need the raw r||s signature pair and a different key import path, and a half-right implementation would be worse than none. The page says so rather than pretending; use your provider's library for ES256.
