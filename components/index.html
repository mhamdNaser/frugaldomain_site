Install from the terminal

One command writes the file into your project. No account, no key, nothing to configure.

npx frugal-cli list --category tables
npx frugal-cli add users-directory-table --dir ./src/ui

Let a coding agent fetch it

The same package runs as an MCP server, so Claude Code or Cursor can search the library and install a component itself.

claude mcp add frugal -- npx -y frugal-cli mcp
