# خطة التكامل: خدمة التحويل على Hugging Face

حالة المستند: **خطة للتنفيذ لاحقاً — لم يُنفَّذ منها شيء بعد.**

---

## ١. لماذا هذه الخطة أصلاً

| المشكلة | التشخيص المُتحقَّق منه |
|---|---|
| العربي يخرج `þ”þóþ®þôþ¨þßþ•` | الـ PDF يحوي الخطوط الـ14 اللاتينية فقط بترميز `WinAnsiEncoding` الذي لا يتضمّن أي حرف عربي |
| `gis` و `netbox` على أسطر منفصلة | قارئ الـ docx كان `regex` على `<w:t>`، ووورد يقسّم الفقرة إلى runs عند أي تغيير تنسيق |
| لا ألوان ولا صور ولا تنسيق | التحويل في المتصفح نصّي فقط، لا محرّك تنسيق |

**الحل الجذري:** LibreOffice هو نفسه محرّك تنسيق وورد، فيعطي مطابقة حقيقية.
لكن تحقّقت أنه **مستحيل على Hostinger**:

```
libreoffice / soffice : غير موجود
apt / yum / dnf       : غير موجود
sudo                  : لا
exec, shell_exec      : DISABLED
```

لذلك ننقل التحويل إلى خدمة منفصلة.

---

## ٢. المعمارية

```
المتصفح
   │  ملف
   ▼
Hugging Face Space (FastAPI + LibreOffice + FFmpeg)
   │  PDF / صوت محوَّل
   ▼
المتصفح  ──(فشل أو نوم)──►  التحويل المحلي الحالي (احتياطي)
```

الخدمة **مستقلة تماماً** عن `api.frugaldomain.site`. لا تغيير في Laravel.

---

## ٣. القرار: ماذا ننقل وماذا نُبقي

| الوظيفة | القرار | السبب |
|---|---|---|
| **المستندات** → PDF | **ينتقل للخدمة** | هنا المشكلة الحقيقية؛ لا بديل عن LibreOffice |
| **الصوت** → صيغة أخرى | **يبقى في المتصفح** | `ffmpeg.wasm` يعمل لديك أصلاً، أسرع، ولا يرفع ملفات المستخدم لطرف ثالث |
| الصور | يبقى كما هو | لا مشكلة فيه |

> **توصية:** لا تنقل الصوت إلا إن احتجت صيغاً لا يدعمها المتصفح. نقله بلا
> حاجة يضيف زمن رفع وتنزيل ويُخرج ملفات المستخدمين من سيطرتك دون مقابل.

الخدمة ستوفّر `/convert/audio` على أي حال، فتستطيع تفعيله لاحقاً بتغيير راية.

## ٤. التعديلات المطلوبة على الكود الحالي

### ٤.١ متغيّرات البيئة

`sydev-front/.env.production` — أضف:
```
VITE_CONVERT_API='https://92naser92-file-converter.hf.space'
```

`sydev-front/.env` — للتطوير (نفس القيمة، أو فارغة لتعطيل الخدمة):
```
VITE_CONVERT_API='https://92naser92-file-converter.hf.space'
```

> **لماذا متغيّر مستقل ولا نستخدم `VITE_API_URL`؟**
> لأن هذه خدمة أخرى بنطاق آخر. وإبقاؤها منفصلة يعني أن تركها فارغة
> يُعطّل الخدمة ويُبقي الموقع يعمل بالتحويل المحلي.

---

### ٤.٢ ملف جديد: `src/api/convertClient.js`

عميل مستقل عن `axios-client` لأن هذا نطاق مختلف ولا يحتاج توكن Laravel.

المسؤوليات:

1. **`isConvertServiceEnabled()`** — هل `VITE_CONVERT_API` مضبوط؟

2. **`wakeConverter()`** — نداء `GET /health` بلا انتظار النتيجة.
   يُستدعى عند فتح صفحة التحويل حتى يستيقظ الـ Space أثناء اختيار المستخدم
   لملفه، فلا ينتظر لاحقاً.

3. **`convertDocument(file, { signal, onProgress })`**
   - `FormData` فيه `file`
   - `fetch` إلى `/convert/document`
   - مهلة سخيّة (٩٠ ثانية) لأن أول طلب قد يوقظ الـ Space
   - يرجع `Blob`
   - يرمي خطأً مفهوماً عند الفشل

4. **`convertAudio(file, targetFormat, opts)`** — نفس النمط.

**نقاط حرجة:**
- لا ترسل `Content-Type` يدوياً مع `FormData`؛ المتصفح يضبط `boundary` بنفسه.
- استخدم `AbortController` ليستطيع المستخدم الإلغاء.
- تحقّق من حجم الملف قبل الرفع (٢٥ ميغا) لتوفير رفع فاشل.

### ٤.٣ تعديل `src/page/site/convertmedia/FileConvert.jsx`

الوضع الحالي بعد إصلاحاتنا: يستدعي `docxToPdf` / `xlsxToPdf` من
`src/utils/officeToPdf.js` محلياً.

**التعديل — لا تحذف المحلي، اجعله احتياطياً:**

```
handleConvert():
  1. إن كانت الخدمة مفعّلة:
       جرّب convertDocument(file)
       عند النجاح → اعرض النتيجة وانتهِ
       عند الفشل  → سجّل السبب وأكمل للخطوة ٢ (لا تُظهر خطأً بعد)
  2. التحويل المحلي الحالي (officeToPdf)
  3. إن فشل الاثنان → أظهر خطأً
```

**أضف للواجهة:**
- حالة `isWakingService` مع رسالة:
  «جارٍ تحضير خدمة التحويل… قد يستغرق ٣٠ ثانية في أول مرة»
  هذه ضرورية وإلا ظنّ المستخدم أن الموقع معطّل.
- شارة صغيرة تبيّن أي مسار استُخدم: «تحويل عالي الدقة» مقابل
  «تحويل سريع (نصّي)» — ليفهم المستخدم سبب اختلاف النتيجة.
- استدعِ `wakeConverter()` في `useEffect` عند فتح الصفحة.
- وسّع الصيغ المقبولة: أضف `doc, ppt, pptx, odt, ods, odp, rtf`
  (الخدمة تدعمها، والمحلي لا) — مع تعطيل الاحتياط المحلي لهذه الصيغ
  لأنه لا يعرفها.

## ٦. اختبارات القبول

قبل اعتبار العمل منتهياً:

- [ ] docx عربي → PDF بعربي **سليم ومتصل الحروف**
- [ ] فقرة مختلطة «مكاتب gis في كل المحافظات» تبقى **سطراً واحداً**
- [ ] الألوان والصور والجداول محفوظة (المكسب الأساسي)
- [ ] xlsx بعدة أوراق → كل ورقة بصفحة
- [ ] ملف أكبر من ٢٥ ميغا → رسالة واضحة لا انهيار
- [ ] ملف تالف → ٤٢٢ برسالة مفهومة لا ٥٠٠
- [ ] الـ Space نائم → رسالة انتظار ثم نجاح
- [ ] الخدمة مُطفأة (`VITE_CONVERT_API` فارغ) → المحلي يعمل
- [ ] رفع من نطاق آخر → يُرفض بـ CORS

| الخطر | الأثر | المعالجة |

| **النوم بعد الخمول** | انتظار ٣٠–٦٠ ثانية | نداء إيقاظ مبكر + رسالة واضحة |
