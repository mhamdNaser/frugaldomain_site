SVG or PNG — which should you download?

Download SVG when the icon has to stay sharp at any size: it is drawn from vector paths, so it scales from a 16px toolbar button to a full-page illustration without losing an edge. Because an SVG is text, you can also recolour it in CSS, animate it, and inline it so it costs no extra request. Choose PNG when the target cannot parse SVG — some email clients, older Android views, and certain app stores — and export at the exact pixel size you need, plus a 2x copy for retina screens.

Licensing and attribution

Icons in this library are free to use in personal and commercial work, with no attribution required and no download limit. You can recolour, resize and modify them, and ship them inside a product you sell. What you cannot do is redistribute the library itself — repackaging the collection as your own icon pack is the one use that is not covered.

Customising before you download

Open any icon to change its colour with a HEX picker, set an exact pixel size, and adjust stroke width on outline icons so they match the weight of the type around them. The preview updates as you edit, and the file you download is the file you saw — there is no separate export step to get wrong.

Do you need an account?

No account is needed to search, customise or download. Creating a free account only adds saved favourites, download history and custom icon sets - the icons themselves are not gated.
